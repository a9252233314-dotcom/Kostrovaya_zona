# Костровая зона 3 × 3 м

Интерактивная объёмная компоновка и схемы разборного металлического каркаса.

Откройте `index.html` в браузере. Установка зависимостей и сборка не нужны.

- Модель вращается мышью или пальцем; колесо меняет масштаб.
- Крышу, людей и раскосы можно скрывать.
- Есть варианты со стульями и скамьями, до шести условных мест.
- В разделе «Схемы узлов» доступны общий каркас, крыша, соединители и основания.
- На главной странице — презентация продукта и партнёрства, шесть переключаемых этапов сборки и фильтруемая ведомость деталей.
- `preliminary-bom.csv` — предварительный состав комплекта (UTF-8, разделитель `;`). Это не карта раскроя.
- `project-brief.txt` — описание проекта для обсуждения участия. Бюджет и доходность не выдуманы и пока не заявлены.
- Исходники главной страницы: `index.html`, `presentation.css`, `presentation.js`, `model.js`. Внешних библиотек и сборки нет.

## Статус

Это предварительная компоновка, а не рабочий проект для изготовления. Сечения, узлы, снеговые и ветровые нагрузки, крепление к основанию, проходы и расстояния до горячих поверхностей требуют проверки. Очаг и люди показаны условно.

## GitHub Pages

Для публикации статических страниц в настройках репозитория выберите Pages → Deploy from a branch, ветку с этими файлами и папку `/ (root)`. Главная страница — `index.html`.
